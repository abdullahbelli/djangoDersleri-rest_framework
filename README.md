# Django Haber Bülteni

Bu proje Django ile geliştirilmiş bir web uygulamasıdır.

## Proje Hedefi

Kullanıcıların güncel haberleri kolayca takip edebileceği bir web uygulaması geliştirmek.
Bu proje Django ile geliştirilmiş bir haber platformudur.

## Proje Hedefi

Kullanıcıların haberleri kategorilere göre takip edebileceği hızlı ve kullanışlı bir web uygulaması geliştirmek.
